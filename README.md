# hana_k_Python

1. 변수 : 단어에다가 값을 저장하는 것
2. 리스트: 여러개의 값을 대괄호를 통해 저장
3. 튜플: 리스트와 동일한데, 수정이 불가능
4. 세트: 집합연산을 하기위한 시퀀스 타입
5. 딕셔너리: 키와 값으로 저장하는 시퀀스타입
6. 조건문: 조건에따라 어떤 코드를 실행할지 결정 if
7. for문: 횟수 제어 반복문
8. while문: 조건이 참일때까지 반복하는 코드
9. continue: 반복문 안에서 다음 반복으로 바로 넘어갈때 쓰는 키워드
10. break: 반복문 안에서 반복을 멈추기 위해 쓰는 키워드
11. 함수: 자주 쓰는 코드들을 하나의 양식으로 정의하여 필요할때마다 호출하는 문법
12. 다중인자: 함수에 넣는 값들을 여러개 넣을 수 있도록 하는 인자.
